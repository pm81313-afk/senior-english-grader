# 學測英文作文智慧批改教室

> 專為高三考生打造的溫和良師益友・全方位作文診斷  
> 設計者：陽明高中 魏山姆 (Sam Wei, Taoyuan Municipal Yang Ming Senior High School)

## 📌 簡介
本專案採用大考中心四項評分指標（內容、組織、文法句構、字彙拼字各 5 分，總分 20 分），能精準分析高三學測英文作文盲點，並提供 B1 基礎紮實版與 B2 頂標金句版的雙軌進階示範。

## ✨ 特點
- **四項評分指標**：專業診斷內容、組織、文法句構、字彙拼字。
- **雙軌範文示範**：提供 B1 基礎版與 B2 頂標金句版範文參考。
- **支援多元輸入**：文字輸入或手寫照片辨識 (OCR)。
- **簡單好用**：支援設定 Gemini API Key 自行使用。
